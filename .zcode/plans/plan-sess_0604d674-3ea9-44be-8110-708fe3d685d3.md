# Agent API + MCP 新增 13F 数据调用

## Context

13F 模块（20 家预设机构季度持仓）目前只有网页端 `/api/form13f/*`（JWT-only）。外部 AI Agent（Cursor/Claude 等）通过 PAT 走 `/api/v1/agent/*` + `guanhe-mcp`，无法访问 13F 数据。目标：把 13F 只读数据接入 Agent 体系，让 Agent 能回答「Bridgewater 最新季度持仓/行业分布/加减仓」类问题。

**已确认决策**：新增独立 PAT scope `form13f:read`（附迁移给存量 PAT 补 scope）；暴露 top5_buys/top5_sells（快照已有，零计算成本）。

## 方案总览

- **HTTP API**：v1 下新增 2 个只读端点（不做 search——仅 20 家预设，manifest 已全覆盖；不做 refresh——Agent API 定位 readonly）
- **数据层**：`AgentService` 经 service_registry 单例复用 `Form13fService`（与 `backend/api/form13f.py:24` 同款获取方式）
- **MCP**：新增 2 个工具 `form13f_manifest` / `form13f_filer`，版本 0.5.1 → **0.6.0**

## 一、后端

1. **`backend/services/personal_token_service.py`**：`ALLOWED_SCOPES` 与 `DEFAULT_SCOPES` 加入 `"form13f:read"`（新 PAT 开箱即用）
2. **`backend/database/migrations/update_personal_tokens_add_form13f_scope.sql`**（新建）：`UPDATE api_personal_tokens SET scopes = scopes || '["form13f:read"]'::jsonb WHERE NOT (scopes ? 'form13f:read');` 给存量 PAT 补 scope
3. **`backend/api/personal_tokens.py`**：L25 scopes 描述加 form13f:read（L52 校验导入 ALLOWED_SCOPES 自动生效）
4. **`backend/schemas/agent.py`**（沿用 `Agent*` 前缀约定）新增：`AgentForm13fPreset`、`AgentForm13fManifestResponse`（精简版 quarters+presets，**不含 top_filers**）、`AgentForm13fHolding`（含 prev_shares）、`AgentForm13fTopChange`、`AgentForm13fQuarterSnapshot`、`AgentForm13fFilerDetailResponse`
5. **`backend/services/agent_service.py`** 新增 2 方法：`form13f_manifest()`、`form13f_filer_detail(filer_id, quarter=None)`（quarter 过滤在响应层做——prev_shares 依赖相邻季不能 SQL 层截断；quarter 不存在返回 None → 端点 404）
6. **`backend/api/agent_v1.py`** 新增：
   - `GET /api/v1/agent/form13f/manifest` — 季度列表 + 20 家预设机构（label→filer_id 映射）
   - `GET /api/v1/agent/form13f/filers/{filer_id}?quarter=` — quarter 可选（不传=全季度趋势对比；传=单季控制 payload）
   - 均用 `require_pat_scopes("form13f:read")` + `_rl()` 限流 headers，异常处理照抄现有端点

## 二、MCP（tools/guanhe-mcp）

7. **`guanhe_mcp/server.py`**：`SERVER_VERSION="0.6.0"`；TOOLS 加 2 工具（描述写明：先 manifest 拿 filer_id；数据滞后=季末后 45 天申报窗口；top20 含期权行；top5 口径=仅股票/ETF 多头按权重变化）——`form13f_manifest`（无参）、`form13f_filer`（filer_id 必填、quarter 可选）；`_call_tool` 加 dispatch；`initialize` instructions 决策树加 13F 行
8. **版本同步**：`pyproject.toml`、`README.md`（标题/安装 URL/工具清单）、构建 wheel 至 `/opt/guanhetech/dist/guanhe_mcp-0.6.0-py3-none-any.whl`

# 13F 手机适配版本实现方案

## Context
后端 13F 数据链路已修复正常（2026Q3 已入库），桌面页 `/form13f`（`Form13FPage.tsx`）可用，但移动端当前直接渲染桌面页：6 列 Table 在窄屏不可用、无导航入口（底部导航只有 5 个 tab，13F 不在其中）。本次按仓库既有移动端模式（参照 `MobileSchedulerPage`，commit 27a5f65）开发专用移动页，功能严格对齐桌面版：机构切换 + 行业分布图 + 季度选择 + Top20 持仓。

## 改动清单（纯前端，无后端/nginx 改动）

### 1. 新建共享模块 `src/components/form13f/form13fShared.tsx`
仿照 `config/schedulerSources.tsx` 防"两端漂移"的先例，从 `Form13FPage.tsx` 原样抽出两端共用部分：`THEME_COLORS`、`fmtMoney/fmtFull/fmtQuarter`、`StatusLabel`（复用 `aiTagChipStyle`）、`isPut/isCall`。桌面页改为 import（视觉零变化）。

### 2. `src/components/form13f/Form13FSectorChart.tsx` 加可选 props（默认值保持桌面现状）
- `height?: number`（默认 420）
- `compact?: boolean`（默认 false）：compact 时 legend 改 `type:'scroll'`、`grid.bottom` 收窄、轴字号微调。图表本身已有 ResizeObserver 自适应宽度，直接复用。

### 3. 新建 `src/pages/MobileForm13FPage.tsx` + `MobileForm13FPage.css`（`m13f-` 前缀，结构性样式）
数据流与桌面完全同口径（manifest → 预设机构默认选第一个 → filer detail → 选中季快照；`hasPrevQuarter`/`maxHoldingPct` 逻辑同语义搬运）。布局：
- **机构切换**：单行横向滑动胶囊条（overflow-x、隐藏滚动条、选中项 `scrollIntoView`），20 家预设
- **摘要头**：机构名 + 最新季市值/持仓数（两行压缩）
- **行业分布卡**：`<Form13FSectorChart compact height={300}>`，点柱切换季度（同桌面）
- **季度选择**：antd `Select`（"2026 Q3"），替代桌面 Tabs（11 个季度 Tabs 在手机放不下）
- **Top20 持仓**：移动列表替代 Table，每行两行布局保留桌面全部 6 列信息：第一行 序号+Issuer+title/Put/Call 胶囊+市值；第二行 % 背景条+股数+Δ Shares（New 胶囊/红绿涨跌，规则同桌面）
- 页脚免责声明同文案；Spin/Empty 状态同桌面；暗色模式走 `themeMode` 内联注入

### 4. `src/TerminalRoutes.tsx`
- 顶部 `lazyWithRetry` 引入 MobileForm13FPage
- TerminalContent 里 `const Form13fComponent = isMobile ? MobileForm13FPage : Form13FPage;`，路由改用该变量（与 Scheduler 换入写法一致）

### 5. `src/components/MobileLayout.tsx` 入口
头像下拉菜单、API Keys 上方加（全用户可见）：`{ key:'/form13f', icon:<FundViewOutlined/>, label:'13F Filings' }`（图标与桌面侧栏一致）。

## 复用清单
`form13fAPI`（`src/services/form13f.ts`，类型已齐备）、`aiTagChipStyle`、`useDashboardSettings`、`useAuthStore`、`useDeviceDetection`、`lazyWithRetry`。

## 验证
1. `cd web-frontend && npx tsc --noEmit` 类型检查通过
2. `GUANHE_ALLOW_BUILD=1 npm run build`（或 scripts/build-safe.sh）构建通过
3. 浏览器（browser-use）375×812 视口：登录 → 头像菜单进 13F → 胶囊滑动/图表点选/季度 Select/持仓列表滚动、亮暗主题切换
4. 桌面回归：`/form13f` ≥768px 仍渲染原桌面页且视觉不变
5. 以上通过后 `npm run deploy`（build + rsync + nginx reload）发布

# facts-report 行情数据链路整体优化

## Context
2026-11-20 报告 FT 表 5 行（SOL/USDC/BNB/DOGE/EURUSD）缺 T 日收盘只能展示 11-18 旧值 + ⚠ 横幅；且实测发现实时覆盖层"当日"列锚点错位（全部 7 个加密币显示两日涨跌）。根因分布在三层：①冻结层在 08:15 行情门后到 ~09:18 冻结间无重拉，加密主源 Yahoo 对 T 日 bar 系统性滞后、次主流币 EODHD bar 09:20-10:00 才发布；②EURUSD/USDJPY 行只读 DB，DB 摄入遇单代码 HTTP 402 静默失败；③实时层 m1d = last/EODHD realtime previousClose，previousClose 中午前不滚动一天。目标：让冻结层尽量拿到 T 日收盘、拿不到时事后自动补齐重发布，实时层锚点永不错位。

## 改动

### 1. 冻结层源优先级修正 — `tools/facts-report/us_close_chart.py`
- `crypto_row()`（~L556）：调换主备——EODHD `_eodhd_eod` 优先（T bar 更及时且 hist 无缺口），Yahoo `_yahoo_series/_yahoo_ohlc` 回退（现成逻辑 `s2[0][0] > s[0][0]` 判断保留）。
- `fx_row()`（~L605）：EURUSD/USDJPY 改为 DXY 同款三级链：EODHD 直连 → Yahoo chart（新增映射 `EURUSD.FOREX→EURUSD=X`、`USDJPY.FOREX→JPY=X`，Yahoo 无配额问题且今日实测 11-19 bar 齐全）→ 现有 DB `_series` 兜底。
- 新增 `_rescue_stale_rows(sections, t)`：在 `render_for_workspace()`（~L796）`build_sections` 之后、`_dump_ft_json` 之前执行——对 strict 组 `as_of != t` 的行按 `row["code"]` 调一次 `_eodhd_eod`，若新序列顶 bar == t 则用 `_changes/_refs/_row` 原有工具重建该行。覆盖利率/指数等 DB 源行的临门补数。

### 2. 事后补齐机制 — 新增 `tools/facts-report/ft_refresh.sh` + crontab
- 脚本逻辑：读 `{ws}/final/charts/ft_sections.json` 的 `stale`，非空才动作（空则 exit 0）；依次跑 `us_close_chart.py --workspace <ws>` → `md2html_report.py <T>` → `register_morning_brief.py --ok <T>`；补齐后 Lark 通知"已修复 N 行"；补不齐则如实保留横幅。
- crontab 增加：`30 10 * * 2-6 /bin/bash /opt/guanhetech/tools/facts-report/ft_refresh.sh >> .../cron.log 2>&1`（10:30 时 EODHD 次主流币 bar 实测已全齐）。

### 3. share_token 稳定化 — `backend/services/morning_brief_report_service.py`
- `complete()`（~L109-130）：UPDATE 分支不再 `share_token=uuid4().hex`，仅 INSERT 分支生成新 token——否则 ft_refresh 重发布会打断早间已分发的链接。

### 4. 实时层锚点修正 — `register_morning_brief.py` + `morning_brief_report_service.py`
- `register_morning_brief.py` ft_live 行规格（~L234）：refs 增加 `"pv": r["last"]`（仅当 `r["as_of"] == t` 时写入——冻结值确为 T 收盘才是合法锚）。
- `_window_changes()`（~L488）：当报价锚定日 `anchor > fallback_anchor(T)` 且 `refs.get("pv")` 存在时，`prev` 用 `pv`（= T 收盘），否则维持现逻辑（realtime previousClose → prev_ref）。DB 降级行（anchor=T）不受影响，rank_live（refs 无 pv）行为不变。前端 JS 无需改动（m1d 由服务端下发）。

### 5. 测试 — `backend/tests/test_morning_brief_live_quotes.py`（新增）
- `_window_changes`：pv 锚（anchor>T+pv → m1d = last/pv）、无 pv 走 previousClose、anchor==T 不用 pv、bp 口径。
- `us_close_chart._rescue_stale_rows`：monkeypatch `_eodhd_eod` 返回带 T bar 的序列 → 行被重建且 as_of=t；返回旧序列 → 行不动。

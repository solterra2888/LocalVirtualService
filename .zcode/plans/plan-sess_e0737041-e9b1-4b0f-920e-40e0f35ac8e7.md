# Feeds Dashboard 手机适配版（MobileFeedsDashboardPage）

## Context

`/feeds-dashboard` 是登录后默认落地页，目前桌面/移动共用 `FeedsDashboardPage`（文档注明"P0 桌面优先，移动端可用"）——移动分支只是把桌面布局压扁：词云整块堆在主题卡片上方（要划过整块词云才见内容）、筛选栏靠 flexWrap 硬换行、"查看全部"在卡片内原地展开撑长页面。本次按仓库移动端惯例做**独立移动页**，产出真正的手机形态；桌面页与后端零改动。

## 交互设计（已定）

1. **吸顶紧凑筛选栏**（sticky，offset = 56 + 任务进度条高度，照抄 MobileDailyPage 的偏移计算）：
   - 第 1 行：日期范围 Segmented（Today/3D/7D）+ 重要性 Segmented（All/Med+/High）
   - 第 2 行：范围 Segmented（My Feeds/Server，localStorage `feeds-dashboard-scope` 同 key）+ 🔥热词按钮（开词云抽屉）+ ⟳ 刷新 + admin ⚡生成快照
2. **Watchlist 命中 chips 行**：有命中的票横滑 chips（点按 = ticker 词过滤），无命中不占位
3. **首页主体**：统计行（X 主题 · Y 条 · 快照时间）+ 主题卡片（可折叠，默认展开，5 条条目，点"查看全部 N →"进入主题详情）
4. **主题详情页**：状态切换（同 MobileDashboardPage selectedStock 模式），顶部返回键 + 主题名 + 计数，IntersectionObserver 无限滚动 `getFeedsDashboardTopicItems`（limit 20）
5. **词云**：底部抽屉（antd Drawer placement="bottom"）内嵌现有 `WordCloudPanel`（maxWords≈50）；选中词 → 关抽屉 + 进入词过滤扁平列表（含 Load more / 清除筛选）
6. **条目预览**：复用 `DailyPreviewDrawer placement="bottom"`，prev/next 导航列表 + `drawerFetchDetail` 路由（`in_user_scope === false` 走 `getFeedsDashboardItemDetail`）照搬桌面逻辑
7. **自动刷新**：5 分钟静默 + visibilitychange 聚焦即刷；抽屉开着 / 词过滤中 / 详情页阅读中 / loading 中跳过

## 实现要点

- 数据加载/状态机从 FeedsDashboardPage 移植：`load()`（Promise.all 主数据+词云、in-flight 防重入）、`handleSelectWord`（topicId 走 topic 过滤、散词/ticker 走精确词过滤）、`loadDrawerNav`（seq ref 防过期响应）——只换 UI 形态不换行为
- 无限滚动 sentinel + fallback scroll listener（照 MobileDailyPage 214-239 模式）
- 主题详情打开时暂停自动刷新（并入 shouldSkip）
- 主题卡片/条目行渲染为移动页内简化版（badge + 渠道图标 + 单行标题 + meta + ≤3 ticker chips，无摘要/英文名），importance 徽章配色照抄 IMPORTANCE_META

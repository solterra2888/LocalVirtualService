# 数据源管理系统文档

## Cron表达式使用说明

本系统提供了完整的Cron表达式使用教程，帮助用户正确配置定时任务。

### 快速访问

1. **在线教程**：在数据源配置页面，点击"Cron表达式"标签旁的"使用说明"按钮
2. **文档文件**：查看 `docs/cron-expression-guide.md` 获取详细说明

### 教程内容

#### 1. 基本概念
- Cron表达式的定义和作用
- 5个字段的含义和取值范围
- 基本格式说明

#### 2. 特殊字符
- `*` - 表示所有值
- `/` - 表示间隔
- `,` - 表示多个值
- `-` - 表示范围
- `?` - 不指定值

#### 3. 常用示例
- 高频任务（每5-15分钟）
- 中频任务（每小时）
- 工作日任务
- 定期任务（每周/每月/每年）

- 时区选择建议

- 测试和监控

### 使用建议

1. **根据数据源选择合适时区**
   - 美股数据：使用 America/New_York
   - 中国数据：使用 Asia/Shanghai

2. **合理设置执行频率**
   - 避免过于频繁的执行
   - 考虑数据源更新频率
   - 平衡实时性和系统性能

3. **测试和监控**
   - 正式使用前测试表达式
   - 定期检查执行日志
   - 及时调整不合理配置

# 任务执行历史CSV下载和清空功能

## 功能概述

在数据源管理（Data Source Management）的"任务执行历史"页面中，新增了CSV下载和清空功能，允许用户将执行日志以CSV格式导出或清空所有日志。

## 功能特性

### 1. 下载按钮位置
- **表格标题栏**：在"任务执行历史"卡片标题右侧

### 2. 下载功能
- 支持下载所有任务的执行日志
- 支持下载特定任务的执行日志（当选择了特定任务时）
- 默认下载最近1000条记录
- 自动生成带时间戳的文件名

### 3. 清空功能
- 支持清空所有任务执行日志
- 带有确认对话框，防止误操作
- 清空后自动刷新页面数据
- 操作不可恢复，需要谨慎使用

### 4. CSV文件内容
导出的CSV文件包含以下字段：
- 任务ID
- 任务名称
- 任务类型
- 开始时间
- 结束时间
- 执行耗时(毫秒)
- 状态
- 结果消息
- 错误消息
- 执行参数

### 5. 文件命名规则
- 所有任务日志：`all_execution_logs_YYYYMMDD_HHMMSS.csv`
- 特定任务日志：`task_execution_logs_{task_id}_YYYYMMDD_HHMMSS.csv`

## 技术实现

### 后端API
- **下载端点**：`GET /scheduler/execution-logs/download`
- **清空端点**：`DELETE /scheduler/execution-logs/clear`
- **参数**：
  - `task_id`（可选）：特定任务ID
  - `limit`（可选）：记录数量限制，默认1000，最大10000
  - `offset`（可选）：偏移量，默认0
- **响应**：CSV文件流或操作结果

### 前端实现
- **服务方法**：
  - `schedulerAPI.downloadExecutionLogsCSV()`
  - `schedulerAPI.clearExecutionLogs()`
- **组件**：`TaskExecutionHistory.tsx`
- **功能**：自动下载文件到用户本地，清空日志并刷新

## 使用说明

### 下载CSV
1. 进入数据源管理页面
2. 导航到"任务执行历史"标签
3. 可选择特定任务进行过滤
4. 点击"下载CSV"按钮
5. 文件将自动下载到浏览器默认下载目录

### 清空日志
1. 进入数据源管理页面
2. 导航到"任务执行历史"标签
3. 点击"清空"按钮
4. 在确认对话框中点击"确认清空"
5. 等待操作完成，页面将自动刷新

## 注意事项

- 下载大量数据时可能需要较长时间
- 建议在下载过程中不要关闭页面
- 下载的文件使用UTF-8编码，支持中文内容
- 文件大小取决于记录数量和内容长度
- **清空操作不可恢复，请谨慎使用**
- 清空操作会删除所有执行日志记录
- 建议在清空前先下载备份

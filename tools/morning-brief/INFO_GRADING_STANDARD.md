# 信息分级标准(重要度 L / 证据 E)

---

## 1. 双轴设计原则

每条信息必须同时获得两个独立的等级,格式 `Lx/Ey`:

- **L(重要度)回答:** 这条信息对当前投资判断有多大冲击?
  ——它是**问题相关**的,同一信息对不同标的、不同阶段的重要度可以不同。
- **E(证据)回答:** 这条信息的来源可验证性有多强?
  ——它是**来源属性**,只取决于信息从哪里来、能否独立核验,与重要与否无关。

两轴正交,不可互相替代:
- 重要(L1)不等于可靠(可能只是 E2/E3 的传闻);
- 可靠(E1)不等于重要(可能只是 L4 的例行披露)。

这与 A00 / A01 的既有立场一致——"usage rule, not a universal credibility rule"——本项目**不做单一维度的可信度排名**,而是用 L、E 两轴分别回答两个不同的问题。

---

## 2. 重要度等级 L(Importance)

判断基准:该信息是否、以及在多大程度上可能改变**投资逻辑、盈利模型或核心风险判断**。

| 等级 | 定义 | 默认处置 |
|---|---|---|
| **L1** | 可能改变投资逻辑、盈利模型或核心风险判断 | 可触发 Model Action / Re-underwrite / Conflict 复核 |
| **L2** | 对判断有实质影响,但暂不足以触发模型调整 | Monitoring / Clarification;等待后续证据积累 |
| **L3** | 具有同行交流或市场情报价值,通常不足以改变方向判断 | 可进观察池;不驱动结论、不进入重点正文 |
| **L4** | 例行记录或低价值噪音 | 原则上不进入重点正文,仅作留档 |

L 的要点:
- L 级是**随上下文浮动**的:同一条 HBM 涨价新闻,对存储标的可能是 L1,对应用软件标的可能只是 L2/L3。
- L 级评的是**该信息本身**,不是该信息所属标的的重要性。

---

## 3. 证据等级 E(Evidence)

判断基准:信息的**来源类型与可独立核验性**。

| 等级 | 定义 | 典型来源 | 约束 |
|---|---|---|---|
| **E1** | 一手、可直接核验的公司或官方证据 | 公司公告、监管披露、交易所文件、公司官网/IR、原始技术资料 | 可作为事实锚点直接使用 |
| **E2** | 可靠专业来源,或多独立来源相互印证 | 权威媒体对公开事件的报道、多个独立来源交叉一致的信息 | 可作为判断依据;表达时须注明来源属性,不得写成直接披露 |
| **E3** | 单一消息源、社交媒体或市场流言 | 单篇未证实报道、社媒发言、市场传闻 | **必须标注未验证;不能单独触发 Model Action** |

E 的要点:
- E 级只看**来源与可核验性**,不看内容听起来多合理。
- 转述降档:E1 信息经第三方转述后,按转述渠道定级(如公司披露被 Reuters 转述,对报告本身是 E2,应回溯原始披露升级为 E1)。
- **主体限定规则(关键细化):** 证据等级以**标的公司自身**为单位。
  - 同业/对手方的一手披露 ≠ 标的自身的 E1。例:SK 海力士称 HBM 售罄至 2029 年,对 MU 是"同业证据"(E2 级支撑行业判断),不构成 MU 自身 E1。
  - 卖方评级、目标价、专家观点**不是经营证据**,不得按 E1 使用;它们最多是 E2 级的分析输入。
  - 启发式推算、翻译换算所得的数字,不得表述为公司或管理层"提供的"数字。
- **fail closed 原则:** 无法核验的数据(不可得的口径、无法交叉验证的接口返回、混合合约页面)**不估算、不沿用旧值、不报告**,并明确标注缺口;缺口本身要写进报告的数据质量声明。

---

## 4. L × E 组合 → 处置门控

等级组合决定该信息**被允许驱动什么**,核心门控规则:

1. **E3 改模禁令(最高优先级):** 无论 L 级多高,E3 信息不能单独触发 Model Action、不能改假设、不能进结论性文字。若 L1/E3(重大但未证实),正确处置是列入验证清单与日历,等证据升档后再动作。
2. **E2 参与判断但不冒充披露:** 可支撑 Reinforcement / Conflict / Monitoring 判断,模型动作仍需 E1 锚点或跨轮次 E2 互证;外部表达按分析口径书写。
3. **E1 才可作硬事实锚点:** 直接写进事实层、可直接驱动模型输入。
4. **L4 不进重点正文**,无论 E 级多高(E1 的例行公告也只是留档)。
5. **L3 默认只进观察池**(如周报第六部分 W2:仅收 L1/L2、具同行交流价值的 L3、或显著异动),不触发任何改模或结论动作。
6. **推测性监管传闻、第三方"预计日期"一律不纳入**确认日历与结论,无论来源声称为何。

典型组合示例(取自 2026-11-02 AI 周报):

| 组合 | 实例 | 处置 |
|---|---|---|
| L1/E1 | MSFT Azure 指引、INTC Q4 指引下修、02476.HK 三季报 | Conflict/Reinforcement + Model Action |
| L1/E2 | SK 海力士/三星 HBM 售罄(经 Reuters) | Reinforcement + Conflict;不直接改模,待原始披露或财报锚定 |
| L2/E2 | 同业 HBM 售罄对 MU 的含义 | Reinforcement + Monitoring;明确"非 MU 自身 E1" |
| L2/E3 | CXMT 低良率 HBM3E 传闻(单一转载) | Monitoring;标注未验证,不触发 Model Action |
| L3/E2 | 防御/金融板块相对表现 | Clarification / Monitoring;仅观察池 |
| L1/E3(假设) | 重大但仅单一源流的监管传闻 | 列入验证清单;不改模、不进正文、不进确认日历 |

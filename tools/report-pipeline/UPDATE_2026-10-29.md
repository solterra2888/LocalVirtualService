# report-pipeline 更新说明（2026-10-29）

这次更新来自对 `build_snapshot.py --date 2026-10-27` 真实运行的评估。那次快照能生成，但有几处会让后续章节直接失败或写出错误数字。下面是问题、改动和用 2026-10-28 重跑的结果。

日常用法仍以 [README.md](README.md) 为准。

## 背景

10-27 的快照有 24MB，其中财报日历约 15MB。`market` 整块为空。在这份快照上跑 Releases 选择，选中的是两行 Building Permits，耐用品订单被漏掉。Surveillance 转录取数失败后，目录里仍留着上一次的文件，会被当成当日转录挂载。

## 改了什么

### 快照取数（`build_snapshot.py`）

- **财报日历不再全表拉取。** 改走 `EarningsCalendarService.get_earnings_calendar_view`：同一 `(code, report_date)` 只留最新抓取行，只留美股普通股。前一交易日盘后和当日要求市值 ≥ $100 亿；未来 5 天要求 ≥ $500 亿。字段只留 `code`、`name`、`report_date`、`session`、`eps_estimate`、`eps_actual`、`eps_surprise_pct`。远端断连重试 3 次。
- **`market` 拆成两块。** `cross_asset`（`market_data_eod`，可回溯）和 Finviz（整表刷新的当前状态，历史日期没有快照）各自记 errors。Finviz 失败不再把跨资产行情一起丢掉。
- **Top Movers 限市值 ≥ $20 亿。** Finviz 的 `market_cap` 单位是百万美元，阈值常量是 `2000`。不设门槛时榜单被微盘股占满。
- **经济日历保留 `comparison`，并写出美东时间。** `mom` / `yoy` / 水平是不同口径。`time` 仍是 UTC，另加 `time_et`（以及跨日时的 `date_et`），夏令时用 `America/New_York`。完全相同的重复行去掉。
- **actual 回填对齐生产同步链路。** EODHD 原始字段是 `type` / `estimate`。回填先 `format_event_data`，再 `calculate_event_impact`，然后 `COALESCE` upsert。这一步写生产库 `economic_events`；调试用 `--no-backfill`。
- **Surveillance 按节目标题里的美东日期匹配交易日 T。** 标题没有日期时，才回退北京日 T+1 那一行。
- **转录：先删旧文件，再取数。** 取数失败不得留下上一次的文本。每次新开连接，最多重试 3 次。超限时保留头 60% 和尾 40%。上限：The Close 12 万、Closing Bell 10 万、Surveillance 22 万字符。
- **摘要去掉开头的客套前言。** 正文不以标题开头、且 500 字内出现第一个 Markdown 标题时，从该标题起算。
- **`prior_odds` 优先用前一交易日的 ZQ 收盘自算。** 没有时才回退最近一期更早的快照。

### 宏观底座（`fetch_macro_pillars.py`）

- **FiscalData 补拍卖字段。** 期限按去掉连字符和空格后的 `7year` 这类键匹配；只取 Note / Bond；字符串 `"null"` 当空值；上一场必须已有中标收益率。
- **`next_fomc_odds.prior`：** 同一合约在前一交易日的收盘，用同样的公式对 EFFR 算出加息概率。
- **Housing Starts 的 `release_series` 改为环比百分比**，不再用开工量的绝对差。
- **nowcasts 网页抓不到时，回退经济日历里最新一条有 actual 的 Atlanta Fed GDPNow。**

### 章节与图表

- **Releases 按事件族选取，每天最多 2 个族**（`run_pipeline.py` 的 `select_tier1_releases`）。优先级：FOMC、非农、CPI、PCE、GDP、PPI、零售、ISM、JOLTS、密歇根、耐用品、房屋开工/许可、成屋销售、10 年期拍卖。排除名称里带 Ex / Excluding / Non-Defense / NSA 的分项。同一族多口径时 m/m 优先，其次水平，最后 y/y。同族其余行放进主行的 `related`。
- **Movers 催化剂**同时看前一交易日盘后公布和当日盘前公布的财报。当日盘后公布的要到下一交易日才反映在股价里。
- **任务书**要求正文时间只引用 `time_et`，并点名选中事件及其 `related` 行。
- **Release 图**只画选中的一线事件；个股图仍是收盘价折线，不是 K 线。

### 日志

`backend/services/economic_events_service.py`：请求参数里的 `api_token` 改为 `***`，异常信息里 URL 上的 token 同样脱敏。10-27 那次运行的终端和既有日志里已经出现过完整密钥，脱敏只防止以后再发生，密钥仍应轮换。

## 验证（2026-10-28）

Finviz 表里只有 2026-10-29 一个快照，所以用 10-28 重测（`snapshot_date ≤ T+1` 刚好命中）。这天也是 FOMC 决议日。

```bash
python tools/report-pipeline/build_snapshot.py --date 2026-10-28
python tools/report-pipeline/run_pipeline.py 2026-10-28 --fake-zcode
```

| 项 | 10-27 实测 | 10-28 修复后 |
|---|---|---|
| 快照体积 | 24MB | 355KB |
| `market` | 整块为空 | 跨资产 16 个代码 + S&P 500 全成分、广度、板块 |
| Releases | 两行 Building Permits | Fed Interest Rate Decision（14:00 ET），FOMC Economic Projections 在 `related` |
| 日历时间 | 只有 UTC `18:00` | `time_et` = `14:00`；`12:30` UTC → `08:30` ET |
| actual 回填 | 抓到 153 条，写入 0 条 | 处理 75 条，更新 75 条（新增 0） |
| 加息概率 prior | 空 | 前一交易日 6.0%，当日 2.0% |
| nowcasts | 网页失败，无替代 | 日历 GDPNow 3.4（as of 10-27） |
| 5 年期拍卖上一场 | FiscalData 为空 | 2026-09-23，5.033%，$700 亿 |
| 7 年期拍卖上一场 | FiscalData 为空 | 2026-09-24，5.085%，$440 亿 |
| Housing Starts 序列 | 绝对差 −67K | 环比 −5.2% |
| Top Movers | 微盘（如 ULBI +145%） | 市值 ≥ $20 亿（AXGN、GMAB、FFIV、VRT 等） |
| Movers 催化剂 | 不看 T-1 盘后 | FFIV、VRT、LPLA、ICLR、CSGP 填了 EPS vs est |
| 确定性核验 | — | `check_results.json` 为 `[]`，`--fake-zcode` 退出码 0 |
| 图表 | — | 跨资产、板块、轮动散点、FOMC Release 图各一张 |

回填那一次对生产库 `economic_events` 做了 75 行 upsert（2026-10-26 至 2026-10-28）。`actual` 用 `COALESCE`，只补不覆盖已有实际值。

真实 ZCode（不带 `--fake-zcode`）还没有跑过。

## 仍未做

- Finviz 热力图、真 RRG、ETF K 线、个股 K 线。现有图是简化替代，见 README「已知边界」。
- Finviz 无法回溯历史交易日。测管线用最新有快照的日期。
- 10-28 的 Closing Bell 没有转录，这是上游摘要本身缺失（`video_id` 在 `subscription_content` 里没有文本），管线只记 `errors`，不补内容。
- Movers 里没有对应财报的行仍写「信源未提及个股消息」，不从别处编催化剂。
- EODHD 共识和 CNT 引用的共识会有偏差（例如耐用品订单），三元组以快照里的 EODHD 值为准。
